# Berlin flexible-jobs founder packet

Research date: 1 September 2026

## Current build status

The active build is now in [`portal/`](./portal): the public job browser, 30-niche taxonomy, internal source control room, evidence-first database contract, deterministic filter gate, and Firecrawl discovery/extraction boundary. **Payments, employer checkout, subscriptions and Stripe are deferred.** They remain research hypotheses in the older documents, not current implementation scope.

This folder contains a decision-ready plan for a Berlin-only flexible-work job board. The chosen direction is deliberately lean: discover unusually early direct-employer vacancies, publish a precise and fresh index, and sell simple employer-authorized listings. It is not a staffing, matching, payroll, or applicant-tracking platform.

The working product concept is **WANN — Berlin jobs that fit your week**. It is a positioning device, not a cleared company name or domain.

## CEO decision in one sentence

Build the source-first portal and prove direct-source coverage plus factual accuracy before adding payments or scaling automation.

## Non-negotiable product promise

Every visible fact must be supported by source evidence. The board prioritizes:

- what it pays, when explicitly stated;
- when the work happens and how many hours it involves, when explicitly stated;
- where it is and how far away it is;
- what language is explicitly required;
- which employment type is explicitly offered;
- when the source was last checked;
- who the real employer is; and
- where the application actually goes.

Missing information is shown as **Not stated** or omitted. It is never completed from probability, page language, job-title stereotypes, or AI guesswork.
